# 럭키 드로우

행사장에서 참가자가 한 명씩 원판을 돌려 경품을 받는 추첨 도구.

## 실행 방법

설치나 서버 없이 `index.html`을 브라우저로 열면 바로 동작한다. 진행자 노트북 한 대에서 열고 화면을 프로젝터나 대형 모니터로 띄워서 쓴다.

## 사용 순서

1. 설정 화면에서 참가자(이름 또는 번호 범위)와 경품(이름, 수량)을 입력하고 추첨을 시작한다.
2. 추첨 화면에서 스페이스바나 돌리기 버튼으로 원판을 돌리고, 다음 버튼으로 다음 참가자로 넘어간다.
3. 모든 경품이 소진되거나 참가자가 없어지면 결과 화면에서 당첨 내역을 CSV로 받거나 복사한다.

## 데이터 저장

진행 상태는 브라우저 `localStorage`에 저장되며, 새로고침 후에도 이어서 진행할 수 있다. 사생활 보호 모드 등 저장이 불가능한 환경에서는 화면 상단에 안내가 표시된다.

## 폰트

참가자 이름과 결과 표시에 쓸 굵은 한글 서체 파일을 넣는 방법은 `fonts/README.md`를 참고한다. 파일이 없어도 시스템 기본 서체로 동작한다.
